# Backlog ý tưởng chưa triển khai

Nơi ghi nhận ý tưởng để xem xét sau. Nội dung backlog không phải yêu cầu triển khai hoặc quy tắc đang áp dụng cho game.

Mỗi ý tưởng có một file Markdown trong nhóm phù hợp: `gameplay/`, `training/`, `social/`, `ai/`, `ui/` hoặc `system/`. Liên kết ý tưởng vào một mục bên dưới; khi đổi trạng thái, chuyển liên kết sang mục tương ứng. Chỉ đưa vào Đã hoàn thành sau khi đã triển khai và kiểm chứng.
