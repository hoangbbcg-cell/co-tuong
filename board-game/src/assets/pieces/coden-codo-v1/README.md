# Bộ quân cờ coden/codo v1

- `coden.png` là ảnh nguồn cho bảy quân Đen: Xe, Mã, Tượng, Sĩ, Tướng, Pháo và Tốt.
- `codo.png` là ảnh nguồn cho bảy quân Đỏ: Xe, Mã, Tượng, Sĩ, Tướng, Pháo và Tốt.
- Mỗi PNG được cắt từ một quân trong ảnh nguồn, xóa nền bàn thành alpha trong suốt và trim sát vùng hiển thị. Không dùng CSS hoặc Tailwind để vẽ hình quân hay tạo bóng.
