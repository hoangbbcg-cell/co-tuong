# Avatar A/B/C experiment — 2026-10-19

Only Lão quân sư is tested; no catalog, ownership or equipped asset is replaced.

- Source: `../lao-quan-su-v2.png`, existing generated artwork; original source/prompt in `../source.md`.
- A uses the existing SmallAvatarPortrait/Bicubic responsive pipeline unchanged.
- B is generated by `scripts/prepare-avatar-ab.ps1`: separable antialiased Lanczos3 in encoded RGB, then unsharp mask with 3×3 Gaussian [1,2,1] kernel, amount 0.20, clamp 0–255. No cropping or composition changes. Opaque PNG.
- 193 unique sizes cover every integer CSS width 48–160 and its 2x source. This covers the existing 136px preview and its responsive reductions. No new dependency. Generation only, no runtime Canvas.
- C waits for a user-designed small-avatar image; local file selection previews only and is not uploaded or persisted.

Open Hồ sơ → Tùy chỉnh avatar → So sánh độ nét A/B/C. The test captures the actual preview width, rounds to CSS integer pixels and shows A/B/C at that same size. It uses a body portal, no transform/filter on the test surface, and object-cover for square artwork. B has explicit 1x/2x sources; A keeps its existing width-descriptor srcset. Sizes outside the generated range report missing B instead of silently resizing to another test size. Runtime diagnostics report selected source size, rendered dimensions and ancestor filter/transform/scale. Browser zoom/OS scaling still affect physical pixels; compare at the same zoom and monitor.

This is a temporary visual experiment, not a claim that B is sharper in the user's browser. No winner selected, no global rollout.
