# Nền banco

Nguồn người dùng: src/assets/boards/source/banco.png. OpenAI built-in image edit phục hồi nền: xóa 32 quân/bóng và chữ Hán ở sông, giữ màu gỗ và lưới 9×10. Sau đó cắt vùng (20,73,1046,1215) từ ảnh phục hồi 1086×1448, lấy từ mép trong khung tối. Không dùng trực tiếp ảnh có quân làm nền.

Chữ HOANGBBCG là HTML in nghiêng, căn giữa sông. Board.tsx ánh xạ các giao điểm ảnh sang canvas hiện tại 1134×1296.
