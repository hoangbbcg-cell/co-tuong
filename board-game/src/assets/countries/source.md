# Country flags

Source: https://github.com/lipis/flag-icons/tree/main/flags/4x3
Retrieved: 2026-10-16. MIT license retained in LICENSE.

Original SVG files, 4:3 viewBoxes; flag backgrounds fill the canvas without outer transparent padding. Bundled locally so Windows browsers show actual artwork without emoji-font support or a runtime CDN connection. Do not add wrapper backgrounds/borders/shadows.
